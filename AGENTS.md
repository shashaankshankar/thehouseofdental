# Development Guidelines

## Project
Static marketing website for a dental practice.

## Priorities
1. Conversion and appointment inquiries
2. Mobile usability
3. Accessibility
4. Fast page loads
5. Maintainable implementation
6. Consistent visual design

## Development rules
- Preserve existing design language unless instructed otherwise.
- Avoid unnecessary dependencies.
- Prefer simple HTML/CSS/JS solutions.
- Do not rewrite unrelated code.
- Do not introduce new abstractions for one-off functionality.
- Maintain responsive behavior.
- Test desktop and mobile layouts.

## Copy
- Avoid generic AI marketing language.
- Keep headings concise.
- Prefer specific claims over adjectives.
- Maintain consistent terminology throughout the site.

## Completion requirements
Before marking implementation complete:
- Run existing tests.
- Check console errors.
- Check responsive layouts.
- Review the diff.
- Confirm every requested acceptance criterion.
