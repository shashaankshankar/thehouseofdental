# Phase 9 release gate

**Result:** local implementation verified; production release blocked
**Date:** 2026-08-05
**Deployment:** not run

## Verified locally

- Nine campaign variants render from one reusable template and are represented in the route registry.
- All campaign variants are `noindex, nofollow`, absent from the generated sitemap, and absent from public/indexable internal links.
- Approved durable service targets receive the campaign canonical only where the campaign record explicitly names that target.
- The event contract contains the requested named events plus diagnostic `form_state` and uses only the approved aggregate fields.
- Form success is downstream of confirmed handler success; click hooks cannot emit success events.
- Attribution is session-scoped, limited to approved UTM keys and referrer hostname, and projects only controlled `campaign_source`.
- No prohibited form, health-interest, referral-friend, raw-referrer, `utm_term`, or page-content field is included in the event builder.
- GA4, tag manager, call tracking, CRM attribution, consent vendor, ad pixels, session recording, and call recording remain unconfigured.
- No network vendor scripts are generated by the local build.
- `npm run validate:phase9` passed and wrote `phase-9-contract-report.json` and `phase-9-campaign-indexability.json`.

## Blocked before production

1. Practice/legal confirmation of final brand, canonical domain, NAP, hours, map, and public campaign approvals.
2. Named clinical/compliance approval for all claims, FAQs, provider/technology facts, urgent wording, and the Phase 4 facial-aesthetics, laser, and QuietNite gates.
3. Approved appointment/contact handler, secure destination, notifications, server validation, spam/rate controls, retention, and live success/failure tests.
4. Approved GA4/tag-manager/call-tracking/CRM/consent vendor configuration, if desired; no placeholder identifiers may be substituted.
5. Approved offer and referral terms, secure backend confirmation, consent model, anti-abuse controls, expiry owner, and legal disclosures.
6. Full local-to-live crawl, redirect verification, Search Console/GBP access, performance review, and named release owner.

This artifact is a local QA and agency-handoff package. It is not a production analytics or campaign signoff.
