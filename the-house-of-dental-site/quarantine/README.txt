PHASE 4 QUARANTINED CARE MATERIALS
==================================

These PDFs are intentionally outside the public asset tree and are not copied
by the static build. They contain clinical or aesthetic instructions whose
device, protocol, offering, provider, or claim source is not yet approved.

Before any file is returned to assets/care-pdfs/, a named clinical owner must
confirm the exact content, practice/compliance must approve the replacement,
and the public page must be rechecked for the same claims and download path.

Quarantined source files:

  complete-care-guide.pdf
  deka-co2-care.pdf
  emage-scan-care.pdf
  hydroderm-care.pdf
  microneedling-care.pdf
  quietnite-care.pdf

QuietNite is additionally held because the local appliance copy conflicts with
the brief's laser-required description. No public care navigation or download
link should imply either protocol until the practice resolves that conflict.
